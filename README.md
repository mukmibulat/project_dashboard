# Проект с использованием разных алгоритмов на основе датасета Amazon Sales.


**1.1** В проекте на данный момент реализована работа с данными о продажах Amazon sales с использованием Python, FastApi и HTML.

- **HashMap** —  быстрый поиск заказа по его `OrderID`.
- **Segment Tree** — подсчёт общей суммы `Quantity` за выбранный диапазон записей и обновление количества для отдельной записи.
- **FastAPI** — API для работы с реализованными структурами данных.
- **HTML-интерфейс** — простейшая страница, через которую можно выполнять поиск заказа, считать сумму и изменять количество.

Данные загружаются из файла Amazon.csv(**100 000 строк и 20 столбцов**).

**1.2 PageRank** 

В проект был добавлен алгоритм PageRank для определения наиболее значимых товаров на основе связей между покупателями и товарами. Для этого был построен двудольный граф, в котором связи учитывают количество купленных товаров. Реализован отдельный модуль `pagerank.py` и API-метод, возвращающий топ-10 товаров по рейтингу. Также добавлено отображение результатов в HTML-интерфейсе.

**1.3 Binary Heap** 

В проект был добавлен алгоритм Binary Heap для определения топ-10 наиболее продаваемых товаров по суммарному количеству проданных единиц (Quantity). Реализована собственная структура данных MinHeap в отдельном модуле binary_heap.py, а также API-метод для получения результатов. Топ-10 товаров отображается в HTML-интерфейсе.

**1.4 Bootstrap** 

В проект был добавлен Bootstrap для статистической оценки средних суммарных расходов одного покупателя на доставленные заказы. Реализована функция многократного формирования выборок с возвращением и расчёта 95% доверительного интервала для среднего значения. Логика вынесена в отдельный модуль bootstrap_analysis.py, результаты доступны через API и отображаются в HTML-интерфейсе.
